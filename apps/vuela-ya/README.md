# Vuela Ya — Colombian Domestic Airline Platform + MCP Server

**Vuela Ya** is a web platform and official Model Context Protocol (MCP) server for a Colombian airline operating strictly domestic routes across Colombia. Customers and AI agents can search flights, compare schedules/prices side-by-side, inspect flight details, interact with live aircraft seat maps, hold seats for 10 minutes, and complete atomic bookings.

Both the web UI and the MCP server share the **same local SQLite database** and the **same business service layer in `/lib/services/`** (no duplicated logic).

> **Language Notice:** All user-facing text (web interface, MCP tool outputs, error responses, labels, buttons, metadata, and seeded airport data) is strictly in **English**.

---

## Key Features

- 🇨🇴 **Domestic Colombian Routes Only:** Connects 10 major Colombian cities (Bogota, Medellin, Cali, Barranquilla, Cartagena, Bucaramanga, Pereira, San Andres, Santa Marta, Cucuta).
- 💺 **Interactive Seat Map:** Aircraft fuselage visualization with Business (2x2 layout, rows 1-4) and Economy (3x3 layout, rows 5-30) cabin classes, exit row indicators, and real-time seat availability.
- ⏱️ **Lazy Seat Hold Expiration:** Selected seats are placed in `held` status for 10 minutes. On any read or write access path, stale holds automatically expire back to `available`.
- 🔒 **Concurrency & Race Condition Safety:** Uses SQLite `IMMEDIATE` transactions and optimistic `version` columns to prevent double-booking or race conditions when multiple sessions select the same seat concurrently.
- 🔑 **Opaque `booking_session_id` Handle:** Cryptographically generated by the server (`crypto.randomUUID()`). Stored in `httpOnly` cookie for the web UI, and passed explicitly in tool parameters for the MCP server (aligned with the July 2026 MCP specification with no transport session dependencies).
- 🤖 **Full MCP Server:** Exposes 8 standard tools accessible via `stdio` (`pnpm mcp`) and over HTTP/SSE (`/api/mcp`).
- 🔄 **Automatic Seed & Clean Reset:** SQLite database (`data/app.db`) automatically seeds on startup and build (`predev` and `prebuild` scripts).

## Tech Stack

- **Framework:** Next.js (App Router) + React 19 + TypeScript
- **Styling & UI:** Tailwind CSS + shadcn/ui components
- **Database:** Local SQLite via `better-sqlite3` (WAL mode enabled, zero external database dependencies)
- **MCP Integration:** `@modelcontextprotocol/sdk` (v1.30.0) + `mcp-handler`
- **Validation:** Zod

## MCP Server & Tools

The Model Context Protocol server can run via **stdio transport** or over **HTTP**:

- **Stdio transport:** `pnpm mcp`
- **HTTP endpoint:** `POST http://localhost:3000/api/mcp`

### Available MCP Tools

1. **`list_airports`**: Lists all served Colombian airports with IATA codes and cities.
   ```json
   { "query": "Bogota" }
   ```
2. **`search_flights`**: Searches scheduled flights between two airports for a specific date (YYYY-MM-DD) with real-time seat availability. Throws a clear error if airport codes are invalid.
   ```json
   {
     "origin": "BOG",
     "destination": "MDE",
     "departure_date": "2026-08-30",
     "passengers": 1,
     "cabin_class": "economy"
   }
   ```
3. **`compare_flights`**: Compares 2 to 4 flights side-by-side.
   ```json
   {
     "flight_ids": ["flight-uuid-1", "flight-uuid-2"]
   }
   ```
4. **`get_flight_details`**: Returns detailed schedule, aircraft model, and seat availability breakdown by cabin class.
   ```json
   {
     "flight_id": "flight-uuid-1"
   }
   ```
5. **`get_seat_map`**: Returns real-time aircraft seat map with cabin layout and statuses (`available`, `held`, `booked`).
   ```json
   {
     "flight_id": "flight-uuid-1"
   }
   ```
6. **`select_seat`**: Temporarily holds a seat for 10 minutes and returns an immutable `booking_session_id`.
   ```json
   {
     "flight_id": "flight-uuid-1",
     "seat_number": "1A",
     "passenger_name": "Maria Camila Gomez"
   }
   ```
7. **`release_seat`**: Immediately releases a held seat back to `available`.
   ```json
   {
     "booking_session_id": "session-uuid",
     "seat_number": "1A"
   }
   ```
8. **`pay`**: Atomically validates holds, converts seats to `booked`, confirms booking, and returns a PNR confirmation code (e.g. `VY-938210`).
   ```json
   {
     "booking_session_id": "session-uuid",
     "passenger_name": "Maria Camila Gomez",
     "passenger_document_id": "1020304050",
     "contact_email": "maria.gomez@example.com"
   }
   ```

## Testing & Verification

### Run End-to-End MCP Tool Test Suite
Tests all 8 MCP tools, invalid input handling, hold creation, hold release, payment confirmation, and lazy expiration:
```bash
pnpm test:mcp
```

### Run Concurrency & Race Condition Test
Simulates 10 concurrent passenger sessions trying to hold the exact same seat at the exact same millisecond:
```bash
pnpm test:race
```
Expected output: Exactly 1 session succeeds, 9 sessions receive clean error rejections, and database integrity is verified.

### Run Linting & Production Build
```bash
pnpm lint
pnpm build
```
